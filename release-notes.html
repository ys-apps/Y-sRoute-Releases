Version 0.9.0

公開ベータ

公開前候補

主な追加機能

  • ゲームごとにTodo、サブTodo、優先度、セクション、チェックリストを管理できます。
  • 手順をチャートとして作成し、タイマー実行、履歴、比較タイム、区間分析、練習記録を利用できます。
  • ゲームDBへ自由な項目を作り、レコード、画像、添付、参照、チェックリストを管理できます。
  • ゲームDBのチェックリストをTodoへ紐づけ、チェック進捗とレベル進捗を表示できます。
  • TodoとChartをOBS Studioのブラウザソースへ表示し、レイアウトやテーマを調整できます。
  • チャート操作用のグローバルショートカットと、ローカル外部制御APIを利用できます。
  • ローカルデータのバックアップと復元、CSV入出力を利用できます。
  • 任意のGoogleログインにより、アカウント進捗とXPを確認できます。

対応環境

  • Windows 11 Home／Pro 24H2以降、x64
  • 日本語
  • GitHub Releases／BOOTHで配布するWindowsインストーラー

利用前に確認してください

  • ログインしなくても、主要なローカル機能を利用できます。
  • 更新前や端末移行前には、設定のデータタブからバックアップを保存してください。
  • 現在確認している問題と制約は既知の問題を確認してください。
